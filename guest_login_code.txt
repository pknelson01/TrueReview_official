FILE: server.js
================================================================

Add this route with the other GET routes.
It looks up a guest account in the database by email,
verifies the password, and logs the user in as that guest account.
This requires a guest user to already exist in the database
with email "guest@truereview.com" and password "guest":

app.get("/guest-login", async (req, res) => {
  const result = await db.query("SELECT * FROM users WHERE email = $1", ["guest@truereview.com"]);
  if (result.rows.length === 0) return res.redirect("/login?error=1");
  const user = result.rows[0];
  const passwordMatch = await bcrypt.compare("guest", user.password);
  if (!passwordMatch) return res.redirect("/login?error=1");
  req.session.user_id = user.user_id;
  res.redirect("/welcome");
});

================================================================
NOTE: Database requirement
================================================================

A guest user must exist in the users table with:
  email:    guest@truereview.com
  password: guest  (stored as a bcrypt hash)

If it does not exist, create it by running a signup through
the app or inserting it directly into the database.
